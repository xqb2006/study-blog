## 一、先看空格位置

| 位置或结构                             | 通常需要的词性       | 例子                                            |
| --------------------------------- | ------------- | --------------------------------------------- |
| `a/an/the + ___`                  | 名词，或形容词 + 名词  | an **ability** / an **important ability**     |
| `介词 + ___`                        | 名词、代词或动名词     | in **society** / by **working**               |
| `主语 + ___`                        | 动词            | People **need**...                            |
| `情态动词 can/will/must/should + ___` | 动词原形          | can **improve**                               |
| `to + ___`                        | 动词原形          | to **develop**                                |
| `be + ___`                        | 形容词、过去分词或现在分词 | is **important** / is **called**              |
| `系动词 look/feel/seem/become + ___` | 形容词           | seem **reasonable**                           |
| `very/so/too/quite + ___`         | 形容词或副词        | very **important** / very **quickly**         |
| `动词 + ___`                        | 副词，或名词作宾语     | work **efficiently** / improve **efficiency** |
| `___ + 名词`                        | 形容词           | serious **problems**                          |
| `___ + 形容词/副词/动词`                 | 副词            | highly **successful** / carefully **analyze** |

## 二、看词尾快速判断

### 1. 名词

常见词尾：

* `-tion/-sion`：education, decision

* `-ment`：development, improvement

* `-ness`：happiness, weakness

* `-ity`：ability, possibility

* `-ance/-ence`：importance, difference

* `-er/-or`：worker, actor

### 2. 动词

常见词尾：

* `-ize/-ise`：realize, organize

* `-ify`：identify, simplify

* `-en`：strengthen, broaden

* `-ate`：activate, regulate

### 3. 形容词

常见词尾：

* `-ful`：useful, successful

* `-less`：careless, harmless

* `-ous`：dangerous, various

* `-al`：natural, cultural

* `-ive`：effective, attractive

* `-able/-ible`：reasonable, possible

* `-ic`：economic, historic

* `-y`：healthy, wealthy

### 4. 副词

最常见：

* `-ly`：carefully, effectively, gradually

* `-ward/-wards`：forward, afterwards

* `-wise`：otherwise, likewise

注意：`-ly` 不一定是副词，例如 `friendly`、`lovely` 是形容词。

## 三、15选10的实际做题步骤

1. **先通读全文，判断文章主题和语境。**

2. **给每个空判断词性**：名词、动词、形容词还是副词。

3. **在选项中筛选对应词性。**

4. **判断词形变化**：单复数、时态、过去分词、现在分词等。

5. **最后检查固定搭配和语义。**

## 四、特别容易考的变化

* `a/an/the + 名词`\
  `an important **achievement**`

* `many/several/these/those + 可数名词复数`\
  `many **factors**`

* `主语 + 动词`，注意主谓一致\
  `The method **works**.`\
  `The methods **work**.`

* `be + 过去分词`：被动语态\
  `is **called**`

* `be + doing`：进行时\
  `is **increasing**`

* `have/has/had + 过去分词`：完成时\
  `has **changed**`

* `介词 + doing`\
  `by **using**`

* `形容词 + 名词`\
  `economic **growth**`

* `副词 + 形容词/动词`\
  `highly **effective**`，`significantly **increase**`

最核心的口诀是：

> **先看位置，判断词性；再看词尾，确定形式；最后看搭配和语义。**
