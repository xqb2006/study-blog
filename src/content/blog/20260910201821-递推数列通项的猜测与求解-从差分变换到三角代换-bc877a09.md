# 递推数列通项的猜测、构造与证明

***

## 一、递推数列通项问题的基本思想

递推数列通常由初始条件和递推关系共同确定。例如：

[\
\
\
\
\
\
\
\
a_1=a,\qquad a_{n+1}=F(n,a_n)\
\
\
\
\
\
\
\
]

或者：

[\
\
\
\
\
\
\
\
a_1=a,\quad a_2=b,\qquad\
\
\
\
\
\
\
\
a_{n+2}=F(n,a_{n+1},a_n)\
\
\
\
\
\
\
\
]

求通项时，常见思路不是直接从递推式中“看出”答案，而是：

1. 根据递推式计算前几项；

2. 观察前几项的差、比、符号和结构；

3. 对原递推式进行变形；

4. 构造一个更简单的辅助数列；

5. 猜测原数列的通项；

6. 通过递推关系和初始条件进行验证。

需要特别注意：

> 由前几项得到的只是猜想，不能作为严格证明。

例如，数列的前几项为：

[\
\
\
\
\
\
\
\
1,2,4,8,\dots\
\
\
\
\
\
\
\
]

可以猜测：

[\
\
\
\
\
\
\
\
a_n=2^{n-1}\
\
\
\
\
\
\
\
]

但必须结合递推关系验证：

[\
\
\
\
\
\
\
\
2a_n=2\cdot2^{n-1}=2^n=a_{n+1}\
\
\
\
\
\
\
\
]

***

## 二、第一步：计算并观察前几项

### 2.1 观察相邻两项之差

计算：

[\
\
\
\
\
\
\
\
a_2-a_1,\quad a_3-a_2,\quad a_4-a_3,\dots\
\
\
\
\
\
\
\
]

如果差值相等，通常是等差数列。

若一阶差分不是常数，可以继续计算二阶差分：

[\
\
\
\
\
\
\
\
\Delta^2a_n

(a_{n+2}-a_{n+1})-(a_{n+1}-a_n)\
\
\
\
\
\
\
\
]

一般来说：

* 一阶差分为常数，通项通常为一次多项式；

* 二阶差分为常数，通项通常为二次多项式；

* 三阶差分为常数，通项通常为三次多项式。

例如：

[\
\
\
\
\
\
\
\
1,4,9,16,25,\dots\
\
\
\
\
\
\
\
]

一阶差分为：

[\
\
\
\
\
\
\
\
3,5,7,9,\dots\
\
\
\
\
\
\
\
]

二阶差分为：

[\
\
\
\
\
\
\
\
2,2,2,\dots\
\
\
\
\
\
\
\
]

因此可以猜测通项为二次式：

[\
\
\
\
\
\
\
\
a_n=An^2+Bn+C\
\
\
\
\
\
\
\
]

结合前几项可以得到：

[\
\
\
\
\
\
\
\
a_n=n^2\
\
\
\
\
\
\
\
]

***

### 2.2 观察相邻两项之比

计算：

[\
\
\
\
\
\
\
\
\frac{a_2}{a_1},\quad\
\
\
\
\
\
\
\
\frac{a_3}{a_2},\quad\
\
\
\
\
\
\
\
\frac{a_4}{a_3},\dots\
\
\
\
\
\
\
\
]

如果比值恒定，则是等比数列：

[\
\
\
\
\
\
\
\
a_n=a_1q^{n-1}\
\
\
\
\
\
\
\
]

如果比值不是常数，但具有规律，例如：

[\
\
\
\
\frac{a_{n+1}}{a_n}

\frac{n+1}{n}\
\
\
\
\
\
\
\
]

则可以连乘：

[\
\
\
\
a_n

a_1\prod_{k=1}^{n-1}\frac{k+1}{k}\
\
\
\
\
\
\
\
]

连乘后得到：

[\
\
\
\
\
\
\
\
a_n=a_1n\
\
\
\
\
\
\
\
]

因此，观察比值不仅可以识别等比数列，还可以发现阶乘、组合数和连乘结构。

***

### 2.3 观察正负号和交替结构

如果数列符号交替出现，通常考虑：

[\
\
\
\
\
\
\
\
(-1)^n\
\
\
\
\
\
\
\
]

例如：

[\
\
\
\
\
\
\
\
1,-2,4,-8,16,\dots\
\
\
\
\
\
\
\
]

可以写成：

[\
\
\
\
\
\
\
\
a_n=(-2)^{n-1}\
\
\
\
\
\
\
\
]

或者：

[\
\
\
\
\
\
\
\
a_n=(-1)^{n-1}2^{n-1}\
\
\
\
\
\
\
\
]

如果奇数项和偶数项规律不同，可以拆分为两个子数列：

[\
\
\
\
\
\
\
\
a_{2n-1},\qquad a_{2n}\
\
\
\
\
\
\
\
]

例如：

[\
\
\
\
\
\
\
\
1,2,1,2,1,2,\dots\
\
\
\
\
\
\
\
]

可以写成：

[\
\
\
\
\
\
\
\
a_{2n-1}=1,\qquad a_{2n}=2\
\
\
\
\
\
\
\
]

***

### 2.4 观察周期性

如果递推中出现负号、倒数或三角函数，数列可能具有周期性。

例如：

[\
\
\
\
\
\
\
\
a_{n+1}=-a_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
a_n=(-1)^{n-1}a_1\
\
\
\
\
\
\
\
]

如果：

[\
\
\
\
\
\
\
\
a_{n+1}=\frac1{a_n}\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
a_{n+2}=a_n\
\
\
\
\
\
\
\
]

因此数列可能是二周期数列。

***

## 三、等差与等比结构

### 3.1 等差型递推

若：

[\
\
\
\
\
\
\
\
a_{n+1}=a_n+d\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=a_1+(n-1)d\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

这是最基本的一阶递推。

更一般地，若：

[\
\
\
\
\
\
\
\
a_{n+1}-a_n=f(n)\
\
\
\
\
\
\
\
]

则逐项累加：

[\
\
\
\
a_n

a_1+\sum_{k=1}^{n-1}f(k)\
\
\
\
\
\
\
\
]

因此，许多递推题本质上是先把递推式整理成差分形式，再利用求和公式。

***

### 3.2 等比型递推

若：

[\
\
\
\
\
\
\
\
a_{n+1}=qa_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=a_1q^{n-1}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

更一般地，若：

[\
\
\
\
\
\
\
\
a_{n+1}=p_na_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=a_1\prod_{k=1}^{n-1}p_k\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

此时需要根据 (p_k) 的形式化简连乘。

***

### 3.3 交替等比型

若：

[\
\
\
\
\
\
\
\
a_{n+1}=-qa_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=a_1(-q)^{n-1}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

这种结构常表现为正负交替，同时绝对值按照等比规律变化。

***

## 四、常系数非齐次线性递推：平移不动点

考虑递推：

[\
\
\
\
\
\
\
\
a_{n+1}=qa_n+b\
\
\
\
\
\
\
\
]

如果直接展开，容易出现较长的计算。更好的方法是寻找一个常数 (c)，使得：

[\
\
\
\
\
\
\
\
c=qc+b\
\
\
\
\
\
\
\
]

这个 (c) 称为不动点。

解得：

[\
\
\
\
\
\
\
\
c=\frac{b}{1-q},\qquad q\ne1\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
u_n=a_n-c\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\begin{aligned}\
\
\
\
\
\
\
\
u_{n+1}\
\
\
\
\
\
\
\
&=a_{n+1}-c\\
&=qa_n+b-c\\
&=q(a_n-c)\\
&=qu_n\
\
\
\
\
\
\
\
\end{aligned}\
\
\
\
\
\
\
\
]

于是 (u_n) 是等比数列：

[\
\
\
\
\
\
\
\
u_n=u_1q^{n-1}\
\
\
\
\
\
\
\
]

还原得到：

[\
\
\
\boxed{\
a_n=\left(a_1-\frac{b}{1-q}\right)q^{n-1}+\frac{b}{1-q}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

### 例

[\
\
\
\
\
\
\
\
a_1=1,\qquad a_{n+1}=2a_n+3\
\
\
\
\
\
\
\
]

不动点满足：

[\
\
\
\
\
\
\
\
c=2c+3\
\
\
\
\
\
\
\
]

所以：

[\
\
\
\
\
\
\
\
c=-3\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
u_n=a_n+3\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
u_{n+1}=2u_n\
\
\
\
\
\
\
\
]

由于：

[\
\
\
\
\
\
\
\
u_1=4\
\
\
\
\
\
\
\
]

所以：

[\
\
\
\
\
\
\
\
u_n=4\cdot2^{n-1}=2^{n+1}\
\
\
\
\
\
\
\
]

因此：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=2^{n+1}-3\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

***

## 五、一般一阶线性递推：归一化方法

一般形式为：

[\
\
\
\
\
\
\
\
a_{n+1}=p_na_n+q_n\
\
\
\
\
\
\
\
]

先考虑对应的齐次递推：

[\
\
\
\
\
\
\
\
a_{n+1}=p_na_n\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
P_1=1,\qquad\
\
\
\
\
\
\
\
P_n=\prod_{k=1}^{n-1}p_k\
\
\
\
\
\
\
\
]

再令：

[\
\
\
\
\
\
\
\
b_n=\frac{a_n}{P_n}\
\
\
\
\
\
\
\
]

由于：

[\
\
\
\
\
\
\
\
P_{n+1}=p_nP_n\
\
\
\
\
\
\
\
]

所以：

[\
\
\
\
\
\
\
\
\begin{aligned}\
\
\
\
b_{n+1}\
\
\
\
&=\frac{a_{n+1}}{P_{n+1}}\\
&=\frac{p_na_n+q_n}{p_nP_n}\\
&=\frac{a_n}{P_n}\
\
\
\
+\frac{q_n}{P_{n+1}}\\
&=b_n+\frac{q_n}{P_{n+1}}\
\
\
\
\end{aligned}\
\
\
\
\
\
\
\
]

这样就把原递推转化成了可求和的差分递推。

### 常见归一化因子

遇到以下形式，可以尝试：

| 递推中出现的结构           | 可以尝试的辅助量    |
| ------------------ | ----------- |
| (na_n)             | (b_n=na_n)  |
| ((n+1)a_{n+1})     | (b_n=na_n)  |
| (n!a_n)            | (b_n=n!a_n) |
| (\frac{n}{n+1}a_n) | (b_n=na_n)  |
| (\frac{1}{n+1}a_n) | (b_n=n!a_n) |
| (\prod p_k)        | 除以连乘因子      |

### 例

[\
\
\
\
\
\
\
\
a_1=1,\qquad\
\
\
\
\
\
\
\
a_{n+1}=\frac{n}{n+1}a_n+\frac1{n+1}\
\
\
\
\
\
\
\
]

两边乘以 (n+1)：

[\
\
\
\
\
\
\
\
(n+1)a_{n+1}=na_n+1\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
b_n=na_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
b_{n+1}=b_n+1\
\
\
\
\
\
\
\
]

又因为：

[\
\
\
\
\
\
\
\
b_1=1\
\
\
\
\
\
\
\
]

所以：

[\
\
\
\
\
\
\
\
b_n=n\
\
\
\
\
\
\
\
]

因此：

[\
\
\
\
\
\
\
\
\boxed{a_n=1}\
\
\
\
\
\
\
\
]

***

## 六、差分法与裂项法

如果递推式可以整理为：

[\
\
\
\
\
\
\
\
a_{n+1}-a_n=f(n)\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
a_n=a_1+\sum_{k=1}^{n-1}f(k)\
\
\
\
\
\
\
\
]

当 (f(n)) 可以裂项时，求解会更加简单。

### 常见裂项公式

[\
\
\
\
\
\
\
\
\frac1{n(n+1)}

\frac1n-\frac1{n+1}\
\
\
\
\
\
\
\
]

[\
\
\
\
\
\
\
\
\frac1{n(n+r)}

\frac1r\left(\frac1n-\frac1{n+r}\right)\
\
\
\
\
\
\
\
]

[

\frac1{\sqrt{n+1}+\sqrt n}

\sqrt{n+1}-\sqrt n\
\
\
\
\
\
\
\
]

### 例

[\
\
\
\
\
\
\
\
a_1=1,\qquad\
\
\
\
\
\
\
\
a_{n+1}-a_n=\frac1{n(n+1)}\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\begin{aligned}\
\
\
\
\
\
\
\
a_n\
\
\
\
\
\
\
\
&=1+\sum_{k=1}^{n-1}\frac1{k(k+1)}\\
&=1+\sum_{k=1}^{n-1}\
\
\
\
\
\
\
\
\left(\frac1k-\frac1{k+1}\right)\\
&=1+1-\frac1n\
\
\
\
\
\
\
\
\end{aligned}\
\
\
\
\
\
\
\
]

因此：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=2-\frac1n\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

## 七、倒数变换

### 7.1 典型倒数结构

遇到：

[\
\
\
\
\
\
\
\
a_{n+1}=\frac{a_n}{1+ca_n}\
\
\
\
\
\
\
\
]

两边取倒数：

[\
\
\
\
\
\
\
\
\frac1{a_{n+1}}

\frac{1+ca_n}{a_n}

\frac1{a_n}+c\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
b_n=\frac1{a_n}\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
b_{n+1}=b_n+c\
\
\
\
\
\
\
\
]

于是 (b_n) 是等差数列。

### 例

[\
\
\
\
\
\
\
\
a_1=1,\qquad\
\
\
\
\
\
\
\
a_{n+1}=\frac{a_n}{1+a_n}\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
b_n=\frac1{a_n}\
\
\
\
\
\
\
\
]

得到：

[\
\
\
\
\
\
\
\
b_{n+1}=b_n+1\
\
\
\
\
\
\
\
]

且 (b_1=1)，所以：

[\
\
\
\
\
\
\
\
b_n=n\
\
\
\
\
\
\
\
]

从而：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=\frac1n\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

***

### 7.2 平移后取倒数

如果递推式中反复出现 (a_n-c)，可以尝试：

[\
\
\
\
\
\
\
\
b_n=\frac1{a_n-c}\
\
\
\
\
\
\
\
]

例如：

[\
\
\
\
\
\
\
\
a_{n+1}=c+\frac{d}{a_n-c}\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
b_n=\frac1{a_n-c}\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
b_{n+1}=\frac1{d}b_n^{-1}\
\
\
\
\
\
\
\
]

此时可能转化为周期递推或等比递推，需要继续分析。

## 八、分式线性递推与不动点

考虑：

[\
\
\
\
\
\
\
\
a_{n+1}

\frac{\alpha a_n+\beta}{\gamma a_n+\delta}\
\
\
\
\
\
\
\
]

这是分式线性递推。

### 8.1 寻找不动点

令 (a_{n+1}=a_n=r)，得到：

[\
\
\
\
\
\
\
\
r=\
\
\
\
\
\
\
\
\frac{\alpha r+\beta}{\gamma r+\delta}\
\
\
\
\
\
\
\
]

即：

[\
\
\
\
\
\
\
\
\gamma r^2+(\delta-\alpha)r-\beta=0\
\
\
\
\
\
\
\
]

求出不动点后，可以尝试：

[\
\
\
\
\
\
\
\
b_n=\frac1{a_n-r}\
\
\
\
\
\
\
\
]

***

### 8.2 两个不动点与交比代换

若不动点为 (r_1,r_2)，可以令：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
b_n=\frac{a_n-r_1}{a_n-r_2}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

经过计算，通常得到：

[\
\
\
\
\
\
\
\
b_{n+1}=kb_n\
\
\
\
\
\
\
\
]

于是：

[\
\
\
\
\
\
\
\
b_n=b_1k^{n-1}\
\
\
\
\
\
\
\
]

再由：

[\
\
\
\
\
\
\
\
\frac{a_n-r_1}{a_n-r_2}

b_1k^{n-1}\
\
\
\
\
\
\
\
]

反解出 (a_n)。

这种方法适合竞赛中的分式递推，考研中一般只要求较简单的倒数或平移形式。

***

## 九、乘积、阶乘与组合数结构

### 9.1 连乘法

若：

[\
\
\
\
\
\
\
\
a_{n+1}=p_na_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
a_n=a_1\prod_{k=1}^{n-1}p_k\
\
\
\
\
\
\
\
]

例如：

[\
\
\
\
\
\
\
\
a_{n+1}=\frac{k+1}{k}a_n\
\
\
\
\
\
\
\
]

连乘后常发生望远镜消去。

***

### 9.2 阶乘归一化

如果递推中出现 (n)、(n+1)、(n!)，可考虑：

[\
\
\
\
\
\
\
\
b_n=na_n,\qquad\
\
\
\
\
\
\
\
b_n=n!a_n\
\
\
\
\
\
\
\
]

例如：

[\
\
\
\
\
\
\
\
a_{n+1}=\frac{a_n}{n+1}\
\
\
\
\
\
\
\
]

反复展开：

[\
\
\
\
\
\
\
\
a_n

\frac{a_1}{2\cdot3\cdots n}\
\
\
\
\
\
\
\
]

因此：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=\frac{a_1}{n!}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

***

### 9.3 组合数结构

如果前几项表现为：

[\
\
\
\
\
\
\
\
1, n, \frac{n(n-1)}2,\dots\
\
\
\
\
\
\
\
]

要考虑组合数：

[\
\
\
\
\
\
\
\
\binom nk\
\
\
\
\
\
\
\
]

如果递推含有：

[\
\
\
\
\
\
\
\
\frac{n-k+1}{k}\
\
\
\
\
\
\
\
]

则可能对应：

[\
\
\
\
\
\
\
\
\binom nk\
\
\
\
\
\
\
\
]

***

### 9.4 双阶乘结构

出现奇数连乘或偶数连乘时，可使用：

[\
\
\
\
\
\
\
\
(2n)!!=2^n n!\
\
\
\
\
\
\
\
]

[\
\
\
\
\
\
\
\
(2n-1)!!=\frac{(2n)!}{2^n n!}\
\
\
\
\
\
\
\
]

例如：

[\
\
\
\
\
\
\
\
\prod_{k=1}^{n-1}\frac{2k+1}{2k}

\frac{(2n-1)!!}{(2n-2)!!}\
\
\
\
\
\
\
\
]

***

## 十、二阶线性递推与特征方程

考虑：

[\
\
\
\
\
\
\
\
a_{n+2}=pa_{n+1}+qa_n\
\
\
\
\
\
\
\
]

设：

[\
\
\
\
\
\
\
\
a_n=r^n\
\
\
\
\
\
\
\
]

代入得：

[\
\
\
\
\
\
\
\
r^{n+2}=pr^{n+1}+qr^n\
\
\
\
\
\
\
\
]

约去 (r^n)，得到特征方程：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
r^2-pr-q=0\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

### 10.1 两个不同特征根

若根为 (r_1,r_2)，则：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=Ar_1^n+Br_2^n\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

常数 (A,B) 由初值确定。

***

### 10.2 二重根

若特征方程有二重根 (r)，则：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=(A+Bn)r^n\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

这里多出的 (n) 是重根带来的。

***

### 10.3 共轭复根

如果特征根为：

[\
\
\
\
\
\
\
\
r(\cos\theta\pm i\sin\theta)\
\
\
\
\
\
\
\
]

则实数形式可以写成：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=r^n(A\cos n\theta+B\sin n\theta)\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

这类递推常与周期性或三角函数有关。

***

### 10.4 降阶法

有些二阶递推不必直接列特征方程，可以构造：

[\
\
\
\
\
\
\
\
b_n=a_{n+1}-\lambda a_n\
\
\
\
\
\
\
\
]

如果能得到：

[\
\
\
\
\
\
\
\
b_{n+1}=\mu b_n\
\
\
\
\
\
\
\
]

则先求 (b_n)，再由：

[\
\
\
\
\
\
\
\
a_{n+1}-\lambda a_n=b_n\
\
\
\
\
\
\
\
]

求出 (a_n)。

***

## 十一、非齐次线性递推

考虑：

[\
\
\
\
\
\
\
\
a_{n+2}+pa_{n+1}+qa_n=f(n)\
\
\
\
\
\
\
\
]

求解分为两部分：

[\
\
\
\
\
\
\
\
a_n=a_n^{(h)}+a_n^{(p)}\
\
\
\
\
\
\
\
]

其中：

* (a_n^{(h)}) 是对应齐次递推的通解；

* (a_n^{(p)}) 是非齐次递推的一个特解。

### 常见特解猜法

| 非齐次项 (f(n))                 | 特解形式                          |
| --------------------------- | ----------------------------- |
| 常数                          | 常数                            |
| 一次多项式                       | 一次多项式                         |
| (n) 次多项式                    | (n) 次多项式                      |
| (c^n)                       | (Ac^n)                        |
| (P(n)c^n)                   | (Q(n)c^n)                     |
| (\sin n\theta,\cos n\theta) | (A\sin n\theta+B\cos n\theta) |

如果猜出的形式已经包含在齐次解中，需要乘以 (n)。如果重复次数更高，则乘以相应的 (n^s)。

***

## 十二、根式递推

### 12.1 直接平方

对于：

[\
\
\
\
\
\
\
\
a_{n+1}=\sqrt{a_n+c}\
\
\
\
\
\
\
\
]

可以先平方：

[\
\
\
\
\
\
\
\
a_{n+1}^2=a_n+c\
\
\
\
\
\
\
\
]

平方能够消除根号，但不一定直接产生通项。之后还需要观察是否可以继续配方、平移或三角代换。

***

### 12.2 共轭变形

遇到：

[\
\
\
\
\
\
\
\
\sqrt{x+1}-\sqrt{x}\
\
\
\
\
\
\
\
]

乘以共轭：

[\
\
\
\
\
\
\
\
\sqrt{x+1}-\sqrt{x}

\frac1{\sqrt{x+1}+\sqrt{x}}\
\
\
\
\
\
\
\
]

这类变形常用于：

* 求和；

* 求极限；

* 证明单调性；

* 比较数列增长速度。

***

### 12.3 根式与三角代换

如果出现：

[\
\
\
\
\
\
\
\
\sqrt{1-a_n^2}\
\
\
\
\
\
\
\
]

可以令：

[\
\
\
\
\
\
\
\
a_n=\sin\theta_n\
\
\
\
\
\
\
\
]

因为：

[\
\
\
\
\
\
\
\
\sqrt{1-\sin^2\theta_n}

|\cos\theta_n|\
\
\
\
\
\
\
\
]

如果出现：

[\
\
\
\
\
\
\
\
\sqrt{1+a_n^2}\
\
\
\
\
\
\
\
]

可以考虑：

[\
\
\
\
\
\
\
\
a_n=\tan\theta_n\
\
\
\
\
\
\
\
]

或：

[\
\
\
\
\
\
\
\
a_n=\sinh t_n\
\
\
\
\
\
\
\
]

具体选择取决于递推中后续是否出现：

[\
\
\
\
\
\
\
\
1+\tan^2\theta=\sec^2\theta\
\
\
\
\
\
\
\
]

或：

[\
\
\
\
\
\
\
\
1+\sinh^2t=\cosh^2t\
\
\
\
\
\
\
\
]

***

## 十三、半角公式递推

半角递推是根式递推中非常重要的一类。

### 13.1 基本对应关系

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
\sqrt{\frac{1+\cos\theta}{2}}

\left|\cos\frac\theta2\right|\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
\sqrt{\frac{1-\cos\theta}{2}}

\left|\sin\frac\theta2\right|\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

因此：

[\
\
\
\
\
\
\
\
a_{n+1}

\sqrt{\frac{1+a_n}{2}}\
\
\
\
\
\
\
\
]

若令：

[\
\
\
\
\
\
\
\
a_n=\cos\theta_n\
\
\
\
\
\
\
\
]

则在符号合适时：

[\
\
\
\
\
\
\
\
a_{n+1}=\cos\frac{\theta_n}{2}\
\
\
\
\
\
\
\
]

于是：

[\
\
\
\
\
\
\
\
\theta_{n+1}=\frac{\theta_n}{2}\
\
\
\
\
\
\
\
]

如果：

[\
\
\
\
\
\
\
\
a_1=\cos\theta_1\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=\
\
\
\
\
\
\
\
\cos\frac{\theta_1}{2^{n-1}}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

***

### 13.2 根式形式

若：

[\
\
\
\
\
\
\
\
a_{n+1}=\sqrt{2+a_n}\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
a_n=2\cos\theta_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\begin{aligned}\
\
\
\
\
\
\
\
a_{n+1}\
\
\
\
\
\
\
\
&=\sqrt{2+2\cos\theta_n}\\
&=2\left|\cos\frac{\theta_n}{2}\right|\
\
\
\
\
\
\
\
\end{aligned}\
\
\
\
\
\
\
\
]

在角度范围合适时：

[\
\
\
\
\
\
\
\
\theta_{n+1}=\frac{\theta_n}{2}\
\
\
\
\
\
\
\
]

***

### 13.3 含负号的半角

若：

[\
\
\
\
\
\
\
\
a_{n+1}=\sqrt{\frac{1-a_n}{2}}\
\
\
\
\
\
\
\
]

设：

[\
\
\
\
\
\
\
\
a_n=\cos\theta_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
a_{n+1}

\sin\frac{\theta_n}{2}

\cos\left(\frac\pi2-\frac{\theta_n}{2}\right)\
\
\
\
\
\
\
\
]

所以：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
\theta_{n+1}

\frac\pi2-\frac{\theta_n}{2}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

若是：

[\
\
\
\
\
\
\
\
a_{n+1}=\sqrt{2-a_n},\qquad a_n=2\cos\theta_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
a_{n+1}

2\sin\frac{\theta_n}{2}

2\cos\left(\frac{\pi-\theta_n}{2}\right)\
\
\
\
\
\
\
\
]

于是：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
\theta_{n+1}

\frac{\pi-\theta_n}{2}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

***

### 13.4 含正弦的半角结构

若：

[\
\
\
\
\
\
\
\
a_n=\sin\theta_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\frac{1+\sin\theta_n}{2}

\sin^2\left(\frac\pi4+\frac{\theta_n}{2}\right)\
\
\
\
\
\
\
\
]

因此：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
\sqrt{\frac{1+\sin\theta_n}{2}}

\left|\sin\left(\frac\pi4+\frac{\theta_n}{2}\right)\right|\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

同理：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
\sqrt{\frac{1-\sin\theta_n}{2}}

\left|\sin\left(\frac\pi4-\frac{\theta_n}{2}\right)\right|\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

因此，含 (1\pm\sin\theta) 的递推可能对应：

[\
\
\
\
\
\
\
\
\theta_{n+1}

## 十六、非线性递推的常见代换

### 16.1 作比值代换

如果递推中出现：

[\
\
\
\
\
\
\
\
a_{n+1}a_{n-1}=a_n^2\
\
\
\
\
\
\
\
]

可以令：

[\
\
\
\
\
\
\
\
b_n=\frac{a_{n+1}}{a_n}\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
\frac{a_{n+2}}{a_{n+1}}

\frac{a_{n+1}}{a_n}\
\
\
\
\
\
\
\
]

即：

[\
\
\
\
\
\
\
\
b_{n+1}=b_n\
\
\
\
\
\
\
\
]

因此 (b_n) 为常数，原数列是等比数列。

### 16.2 取对数

对于正项幂递推：

[\
\
\
\
\
\
\
\
a_{n+1}=a_n^{p_n}\
\
\
\
\
\
\
\
]

令：

[\
\
\
\
\
\
\
\
b_n=\ln a_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
b_{n+1}=p_nb_n\
\
\
\
\
\
\
\
]

例如：

[\
\
\
\
\
\
\
\
a_1=e,\qquad a_{n+1}=a_n^2\
\
\
\
\
\
\
\
]

有：

[\
\
\
\
\
\
\
\
\ln a_n=2^{n-1}\
\
\
\
\
\
\
\
]

因此：

[\
\
\
\
\
\
\
\
\boxed{\
\
\
\
\
\
\
\
a_n=e^{2^{n-1}}\
\
\
\
\
\
\
\
}\
\
\
\
\
\
\
\
]

***

### 16.3 平方代换

如果递推含 (a_n^2)，可考虑：

[\
\
\
\
\
\
\
\
b_n=a_n^2\
\
\
\
\
\
\
\
]

但要注意，平方可能丢失符号信息。若原数列不保证非负，不能只根据 (a_n^2) 直接还原 (a_n)。

\
\
\
\
\
\
\

\
\
\
\
\
\
\

\
\
\
\
\
\
\

\
\
\
\
\
\
\

可以考虑：

[\
\
\
\
\
\
\
\

\
\
\
\
\
\
\

[\
\
\
\
\
\
\
\

\
\
\
\
\
\
\

\
\
\
\
\
\

## 十七、不变量与辅助数列

### 17.1 寻找守恒量

如果能够证明：

[\
\
\
\
\
\
\

\
\
\
\
\
\
\

[\
\
\
\
\
\
\
\
F(a_{n+1},a_n)=C\
\
\
\
\
\
\
\
]

其中 (C) 由初值确定。

这种 (F) 称为不变量。

### 17.2 构造和与差

如果递推中出现相邻项的和差，可以尝试：

[\
\
\
\
\
\
\
\
b_n=a_{n+1}+a_n\
\
\
\
\
\
\
\
]

或：

[\
\
\
\
\
\
\
\
b_n=a_{n+1}-a_n\
\
\
\
\
\
\
\
]

有时原递推虽然复杂，但 (b_n) 会满足简单的等差或等比递推。

***

### 17.3 构造乘积不变量

如果两个数列满足：

[\
\
\
\
\
\
\
\
a_{n+1}b_{n+1}=a_nb_n\
\
\
\
\
\
\
\
]

则：

[\
\
\
\
\
\
\
\
a_nb_n=C\
\
\
\
\
\
\
\
]

这可以把二元递推降为一元递推。

## 十八、只求极限时的方法

并非所有递推题都适合或要求求显式通项。有些题目只要求极限，此时重点是：

1. 证明数列有界；

2. 证明数列单调；

3. 设极限为 (L)；

4. 代入递推关系求 (L)。

例如：

[\
\
\
\
\
\
\
\
a_{n+1}=\sqrt{2+a_n}\
\
\
\
\
\
\
\
]

若已知数列收敛于 (L)，则：

[\
\
\
\
\
\
\
\
L=\sqrt{2+L}\
\
\
\
\
\
\
\
]

平方得：

[\
\
\
\
\
\
\
\
L^2-L-2=0\
\
\
\
\
\
\
\
]

所以：

[\
\
\
\
\
\
\
\
L=2\quad\text{或}\quad L=-1\
\
\
\
\
\
\
\
]

由于数列各项非负，故：

[\
\
\
\
\
\
\
\
\boxed{L=2}\
\
\
\
\
\
\
\
]

但“由递推求出的候选极限”还需要结合单调性、有界性和定义域筛选，不能直接认为一定收敛。

## 二十、猜想后的严格验证

### 20.1 一阶递推的归纳验证

若猜测：

[\
\
\
\
\
\
\
\
a_n=f(n)\
\
\
\
\
\
\
\
]

验证步骤如下：

1. 验证初值： [ a_1=f(1) ]

2. 假设： [ a_n=f(n) ]

3. 由递推关系： [ a_{n+1}=F(n,a_n) ]

4. 代入归纳假设： [ a_{n+1}=F(n,f(n)) ]

5. 证明： [ F(n,f(n))=f(n+1) ]

***

### 20.2 二阶递推的验证

二阶递推需要验证两个初始项：

[\
\
\
\
\
\
\
\
a_1=f(1),\qquad a_2=f(2)\
\
\
\
\
\
\
\
]

归纳步骤中同时假设：

[\
\
\
\
\
\
\
\
a_n=f(n),\qquad a_{n+1}=f(n+1)\
\
\
\
\
\
\
\
]

再推出：

[\
\
\
\
\
\
\
\
a_{n+2}=f(n+2)\
\
\
\
\
\
\
\
]

***

### 20.3 必须检查的细节

验证时还要检查：

* 根式内是否非负；

* 分母是否为零；

* 取倒数是否合法；

* 取对数是否要求 (a_n>0)；

* 平方是否引入多余解；

* (\sqrt{x^2}=|x|) 的绝对值；

* 三角代换中的象限和符号；

* 递推关系的起始下标。

## 二十二、总结：递推猜通项的核心框架

递推数列的通项猜测可以归纳为以下几类：

### 1. 直接发现简单数列

通过差分、比值、符号和周期，识别：

* 等差数列；

* 等比数列；

* 多项式数列；

* 交替数列；

* 周期数列。

### 2. 构造简单的辅助数列

通过：

* 平移；

* 取倒数；

* 取对数；

* 作比值；

* 乘 (n)；

* 乘 (n!)；

* 除以连乘因子；

* 构造和、差、乘积。

将原递推化为等差、等比或可求和形式。

### 3. 识别特殊结构

通过：

* 特征方程；

* 半角公式；

* 倍角公式；

* 三角代换；

* 双曲函数；

* 不变量；

* 矩阵；

* 生成函数。

处理线性、高阶或非线性递推。
